# Sprint 4: Preparación para Despliegue, QA y Sustentación Final

- **Duración:** Semanas 16 a 18.
- **Hito de Evaluación:** **PROYECTO FINAL / SUSTENTACIÓN** (Semana 18).
- **Objetivo:** Auditoría de calidad, afinamiento de rendimiento, empaquetado agnóstico (JAR ejecutable y bundle estático de frontend), documentación completa y preparación de la demostración para la sustentación.

---

## 👥 Asignación de Roles y Tareas (Sprint 4)

| Integrante / Rol | Foco Principal en Sprint 4 | Entregables Específicos |
| :--- | :--- | :--- |
| **Integrante 4 (Scrum Master S4)** | Coordinación de cierre, demo y presentación | Diapositivas ejecutivas, guion de sustentación y control de tiempos |
| **Integrante 1 (DevOps / Lead)** | Empaquetado agnóstico y validación de despliegue | Configuración de artefactos ejecutables (`jar` de Spring Boot y build optimizado de Vite) |
| **Integrante 2 (QA Lead)** | Pruebas End-to-End (E2E) y Sanity Testing | Matriz de pruebas finales de todos los flujos de usuario (happy path y edge cases) |
| **Integrante 3 (Tech Writer)** | Consolidación y Cierre de Documentación | Auditoría final de la carpeta `docs/` y actualización del `README.md` principal |
| **Integrante 5 (Frontend Dev)** | Polish Visual y Accesibilidad UI | Corrección de detalles de diseño, feedback de carga (`Skeleton`) y responsive checks |
| **Integrante 6 (Backend Dev)** | Optimización de Consultas y Logging | Verificación de tiempos de respuesta de endpoints e índices en PostgreSQL |
| **Integrante 7 (Full Stack)** | Configuración de Datos de Demostración (Demo Seeds) | Escenarios de prueba con vuelos en diferentes estados listos para la defensa |

---

## 🏆 Checklist de Sustentación Final
- [ ] Aplicación Full Stack 100% funcional y sin errores en consola.
- [ ] Flujo completo: Búsqueda -> Comparación -> Registro/Login -> Guardado de Viaje -> Alerta recibida -> Tablero en vivo.
- [ ] Documentación técnica completa y estructurada en `docs/`.
- [ ] Presentación y demostración en vivo lista para el jurado docente.
